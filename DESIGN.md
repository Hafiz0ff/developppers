# Design System & UI Specifications

## Color Palette
- **Primary / Accent**: Emerald / Teal (`#0D9488` / `emerald-600`) — trust, real estate, growth.
- **Secondary**: Slate / Zinc (`slate-900` for text, `slate-100` for subtle cards).
- **Status Colors**:
  - Available (Свободно): Green (`emerald-500`)
  - Reserved (Забронировано): Amber/Yellow (`amber-500`)
  - Sold (Продано): Slate/Red (`slate-400` / `red-500`)

## Typography
- Main Font: Inter / Geist Sans
- Headings: Bold, clean, high contrast.

## Key UI Components
1. **Developer Header**: Custom badge, logo, contact phone, direct Telegram button.
2. **Unit Chessboard (Шахматка)**: Grid showing floor layout with color-coded unit statuses.
3. **Classifieds Grid**: Compact Avito-style cards with price, photo, region, and phone button.
