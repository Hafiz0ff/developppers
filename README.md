> **Maskani (Sogd Realty)** — цифровая PropTech-платформа нового поколения для рынка первичной и вторичной недвижимости Согдийской области и всего Таджикистана (Худжанд, Душанбе, Бустон, Истаравшан, Гулистон и др.). Платформа объединяет каталог верифицированных новостроек с интерактивными шахматками, конструктор комплексной сделки (квартира + паркинг + кладовая), сквозное CRM-бронирование, вторичный рынок без посредников, платёжные шлюзы Таджикистана (`Корти Милли`, `DC / Dushanbe City`, `Alif Salom`, `Эсхата Онлайн`), модуль сравнения объектов, рекламный аукцион, управляемую URL-архитектуру и автоматизацию SEO с кабинетом Super Admin.

🌐 **Production Demo**: [https://sogd-realty.vercel.app](https://sogd-realty.vercel.app)

## Ключевые продуктовые модули

### 1. Управляемая URL-архитектура и автоматизация SEO (ТЗ v1.7 FINAL)
- **Единый источник правды (`src/lib/seo/url-resolver.ts`)**: централизованная генерация канонических URL, локализованных путей (`RU` — без префикса, `TG` — `/tg/`, `EN` — `/en/`), `self-canonical`, взаимного `hreflang` (`ru`, `tg`, `en`, `x-default`) и метаданных.
- **Реестр 301-алиасов с защитой от цепочек и циклов (`src/lib/seo/url-alias-store.ts`)**: при смене категории или slug старый URL регистрируется и перенаправляется на актуальный канонический URL одним серверным 301. Цепочки редиректов (`A -> B -> C`) автоматически схлопываются в прямой переход (`A -> C`, `B -> C`).
- **Синхронизированные Breadcrumbs и Schema.org (`RealEstateListing`, `BreadcrumbList`)**: видимая навигационная цепочка и структурированные данные генерируются из единой модели данных.
- **Zero Manual SEO для партнёров**: C2C, риэлторы, застройщики и агентства заполняют только понятные бизнес-поля (характеристики объекта, адрес, фото, описание) и выбирают утверждённую категорию. H1, Title, Description, URL, canonical, hreflang, JSON-LD и sitemap формируются автоматически.
- **Управление таксономией и SEO в Super Admin (`/super-admin/categories`)**:
  - Редактирование категорий и локализованных названий (RU/TG/EN);
  - Режимы `AUTO` (авто-генерация slug) и `MANUAL` (сохранение slug при переименовании);
  - Предпросмотр миграции (Preview) с расчётом затронутых URL и карты редиректов до подтверждения;
  - Управление allowlist индексируемых категорий (`indexable: true/false`);
  - Пакетный аудит **DRY RUN** фактических данных и масштабируемость 10 000+ записей без записи фиктивных строк в БД.
- **Sitemap & Robots**: генерация `sitemap.xml`, `sitemap-index.xml` и `robots.txt`, содержащих исключительно канонические индексируемые 200 URL.

### 2. Витрина новостроек и интерактивный генплан (`/`, `/projects`, `/projects/[slug]`)
- **Многомерная фильтрация и гео-поиск**: фильтрация ЖК по городу, району, классу жилья (`Эконом`, `Комфорт`, `Бизнес`, `Премиум`), сроку сдачи, комнатности, бюджету в сомони (`TJS`) или долларах (`USD`), ипотеке и беспроцентной рассрочке.
- **Синхронизированный Split-View с картой 2ГИС / MapGL**: двусторонняя привязка карточек ЖК и полигонов/маркеров на карте (выделение карточки подсвечивает пин на карте и наоборот, фильтрация по `bbox` видимой области).
- **Интерактивный разрез корпуса («План секции») и Шахматка (`Chessboard`)**:
  - Наведение и клик по этажу в SVG-разрезе корпуса мгновенно отображают доступные квартиры, площади и цены.
  - Полная шахматка квартир по корпусам, подъездам и этажам с цветовой индикацией статусов (`Свободна`, `Бронь`, `Продана`) и карточкой планировки.

### 3. Сценарий «Заявки на бронирование и звонки» + Конструктор сделки (`CRM Booking & Deal Builder`)
- **Блок «Стоимость выбранной квартиры»**: синхронизация выбранного лота из «Плана секции» или «Интерактивной шахматки» на карточке ЖК (`/projects/[slug]`), расчёт рассрочки 0% и валют `TJS / USD`.
- **Блок «С паркингом и кладовой покупка выгоднее»**: динамический заголовок, модальные шахматки подземного паркинга (`ParkingChessboardModal`) и кладовых (`StorageChessboardModal`) с проверкой статуса `"available"`.
- **Блок «Общая стоимость» (Summary)**: позиционная детализация сделки (`Квартира + Паркинг + Кладовая`) с кнопками удаления `[×]` и автопересчётом `Итого`.
- **Оверлеи «Забронировать» и «Звонок» (`LeadRequestDrawer`)**: выдвижная панель слева (`slide-in-from-left`), выбор времени («В течение 15 минут» / «Выбрать время»), чекбокс согласия с ПДн (`/privacy`) и серверная верификация **Zero Client Trust** (`POST /api/crm/lead-booking`).

### 4. Кабинет застройщика и ERP-коннектор (`/developer-admin`)
- **Управление сценарием бронирования и звонков (`DeveloperCrmBookingSettings`)**: 3 состояния блока CRM, иконка вопроса `(?)` слева от тумблера с hover-поповером и модальным окном справки, авто-отключение тумблера при разрыве CRM.
- **Универсальный шлюз импорта из строительной ERP (`POST /api/erp/sync`)**: приём данных из `1С:Предприятие`, `Profitbase`, `MacroCRM` с аудитом изменений.
- **Живая лента входящих лидов**: карточки комплексных сделок и слоты обратного звонка.

### 5. Вторичный рынок, Аренда и Монетизация объявлений (`/classifieds`, `/post-ad`)
- Каталог частных объявлений и мастер подачи (`/classifieds/new`).
- VAS-пакеты продвижения: **«Поднять в ТОП на 7 дней»** (`10 смн`), **«Выделение цветом»** (`8 смн`), **«Срочная продажа 🔥»** (`12 смн`) и **«Турбо-продажа 3-в-1»** (`24 смн`).

### 6. Платёжные шлюзы Таджикистана (`FinTech Payment Engine`)
- Поддержка национальных методов: **Корти Милли**, **Dushanbe City (`DC Next QR`)**, **Alif Salom**, **Эсхата Онлайн**.

### 7. Модуль сравнения объектов (`/compare`)
- Сравнение новостроек и вторичных квартир, режим «Только отличия» и автоподсветка лучших метрик.

### 8. Рекламная платформа и Кабинет Суперадмина (`/advertiser`, `/super-admin`)
- Аукцион нативной рекламы `CPC/CPM`, антифрод-защита кликов, сквозная аналитика монетизации и модерация.

## Технологический стек

| Категория | Технологии |
| :--- | :--- |
| **Framework** | Next.js 16.4 (`App Router`, Server & Client Components, Edge Middleware, Route Handlers) |
| **UI & Язык** | React 19.2.4, TypeScript 5 (`strict: true`), Lucide Icons (`lucide-react`) |
| **Стилизация** | Tailwind CSS v4 (`@tailwindcss/postcss`), CSS Variables, Glassmorphism & Adaptive Sheets |

```bash

cd sogd-realty

# 2. Установить зависимости
npm install

# 3. Запустить сервер разработки
npm run dev

# 4. Запустить все 187 тестов
npx tsx --test 'src/**/*.test.ts'
```

## Тестирование

В проекте реализовано **187 автоматизированных тестов** (модульных и интеграционных):
- Тесты URL-архитектуры и SEO (`src/lib/seo/seo-engine.test.ts`):
  - `AC-01`: префиксы локалей (RU без префикса, TG `/tg/`, EN `/en/`), `self-canonical`, взаимный `hreflang`;
  - `AC-02` / `AC-18`: пересчёт URL и Schema.org при смене категории (аренда $\rightarrow$ продажа);
  - `AC-03` / `AC-21`: режимы slug `AUTO` и `MANUAL` в Super Admin;
  - `AC-04` / `AC-12`: устранение цепочек редиректов (`A -> C`, `B -> C`) и защита от циклических редиректов;
  - `AC-07` / `AC-13`: синхронизация видимых хлебных крошек и `BreadcrumbList` JSON-LD;
  - `AC-14`: проверка включения в sitemap только канонических индексируемых 200 URL;
  - `AC-16`: независимость видимого имени («Аренда») и slug (`arenda` / `snyat`);
  - `AC-23`: новые категории закрыты от индексации по умолчанию;
  - `AC-25` / `AC-32`: бенчмарк масштабируемости на 10 000+ записей в памяти за 85 мс;
  - `AC-26` / `AC-28`: безопасный `DRY RUN` аудит и строгая идемпотентность;
  - `AC-30`: логирование исключений без выдумывания фиктивных данных.
- Тесты сценария бронирования и звонков (`src/lib/crm-booking.test.ts`);
- Тесты платёжных шлюзов и VAS-монетизации (`src/lib/payment-vas.test.ts`);
- Тесты строительной ERP (`src/lib/erp-engine.test.ts`);
- Тесты модуля сравнения (`src/lib/compare-store.test.ts`);
- Тесты рекламного аукциона и аналитики (`src/lib/ad-engine.test.ts`).
