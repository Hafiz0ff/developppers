> **Maskani (Sogd Realty)** — цифровая PropTech-платформа нового поколения для рынка первичной и вторичной недвижимости Согдийской области и всего Таджикистана (Худжанд, Душанбе, Бустон, Истаравшан, Гулистон и др.). Платформа объединяет каталог верифицированных новостроек с интерактивными шахматками, конструктор комплексной сделки (квартира + паркинг + кладовая), сквозное CRM-бронирование, вторичный рынок без посредников, платёжные шлюзы Таджикистана (`Корти Милли`, `DC / Dushanbe City`, `Alif Salom`, `Эсхата Онлайн`), модуль сравнения объектов, рекламный аукцион и кабинет застройщика с прямым импортом из строительных ERP.

🌐 **Production Demo**: [https://sogd-realty.vercel.app](https://sogd-realty.vercel.app)

## Ключевые продуктовые модули

### 1. Витрина новостроек и интерактивный генплан (`/`, `/projects`, `/projects/[slug]`)
- **Многомерная фильтрация и гео-поиск**: фильтрация ЖК по городу, району, классу жилья (`Эконом`, `Комфорт`, `Бизнес`, `Премиум`), сроку сдачи, комнатности, бюджету в сомони (`TJS`) или долларах (`USD`), ипотеке и беспроцентной рассрочке.
- **Синхронизированный Split-View с картой 2ГИС / MapGL**: двусторонняя привязка карточек ЖК и полигонов/маркеров на карте (выделение карточки подсвечивает пин на карте и наоборот, фильтрация по `bbox` видимой области).
- **Интерактивный разрез корпуса («План секции») и Шахматка (`Chessboard`)**:
  - Наведение и клик по этажу в SVG-разрезе корпуса мгновенно отображают доступные квартиры, площади и цены.
  - Полная шахматка квартир по корпусам, подъездам и этажам с цветовой индикацией статусов (`Свободна`, `Бронь`, `Продана`) и карточкой планировки.

### 2. Сценарий «Заявки на бронирование и звонки» + Конструктор сделки (`CRM Booking & Deal Builder`)
- **Блок «Стоимость выбранной квартиры»**: мгновенная синхронизация выбранного лота из «Плана секции» или «Интерактивной шахматки» на карточке ЖК (`/projects/[slug]`), включая бейдж `В рассрочку 0%`, расчёт ежемесячного платежа и переключение валют `TJS / USD`.
- **Блок «С паркингом и кладовой покупка выгоднее»**:
  - Динамический заголовок и кнопки `+ Кладовая` / `+ Машино-место` в зависимости от наличия свободных (`available`) лотов в проекте.
  - Интерактивные модальные шахматки подземного паркинга (`ParkingChessboardModal`) и кладовых помещений (`StorageChessboardModal`) с карточкой «Характеристики и стоимость» и проверкой актуального статуса перед добавлением.
- **Блок «Общая стоимость» (Summary)**:
  - Позиционная детализация выбранной квартиры, машино-места и кладовой с кнопками удаления `[×]` по каждой позиции и автопересчётом `Итого`.
- **Оверлеи «Забронировать» и «Звонок» (`LeadRequestDrawer`)**:
  - Выдвижная панель слева (`slide-in-from-left` на десктопе, адаптивный `bottom-sheet` на мобильных).
  - Радиокнопки времени связи: **«В течение 15 минут»** (по умолчанию) или **«Выбрать время»** (выпадающие списки `Сегодня / Завтра` и слоты `09:00–22:00` под полем телефона).
  - Квадратный чекбокс согласия с политикой обработки персональных данных (`/privacy`), по умолчанию **не проставлен** (`false`).
  - Серверная верификация **Zero Client Trust** (`POST /api/crm/lead-booking`): проверка принадлежности лотов проекту застройщика (`DEVELOPER_MISMATCH`), активности CRM (`CRM_NOT_ACTIVE`), включённого сценария (`FEATURE_DISABLED`), статуса `"available"`, пересчёт цен на сервере в `TJS`, защита от дублей (10 сек) и сохранение статуса объектов неизменным до подтверждения менеджером в CRM.

### 3. Кабинет застройщика и ERP-коннектор (`/developer-admin`)
- **Управление сценарием бронирования и звонков (`DeveloperCrmBookingSettings`)**:
  - 3 состояния блока: `CRM не подключена` (промо-текст + кнопка «Подключить CRM»), `CRM подключена, сценарий выключен` (кнопка «Включить сценарий»), `Сценарий включён` (промо-тексты скрыты, активен тумблер).
  - Иконка вопроса `(?)` слева от тумблера с поддержкой `hover`-поповера на десктопе и модального окна «Сценарий бронирования и звонков» при клике/на мобильных.
  - Автоматическая деактивация тумблера при отключении интеграции с CRM.
- **Управление шахматкой и ценами в реальном времени**: массовая переоценка (`Repricing`), изменение статусов квартир, машино-мест и кладовых.
- **Универсальный шлюз импорта из строительной ERP (`POST /api/erp/sync`)**:
  - Приём данных из `1С:Предприятие`, `Profitbase`, `MacroCRM`, `AmoCRM` и Excel/CSV-выгрузок.
  - Интерактивный симулятор ERP-вебхуков с журналом синхронизации (`Audit Log`) и идемпотентной обработкой.
- **Живая лента входящих лидов и CRM-броней**: карточки комплексных сделок (`Квартира + Паркинг + Кладовая`), слот обратного звонка и быстрые действия менеджера.

### 4. Вторичный рынок, Аренда и Монетизация объявлений (`/classifieds`, `/post-ad`)
- **Доска частных объявлений**: продажа и аренда квартир, домов/хавли и коммерческой недвижимости без посредников.
- **Мастер подачи объявления (`/post-ad`)**: пошаговая форма с гео-привязкой, проверкой параметров и расчётом рыночной оценки.
- **VAS-монетизация объявлений (Freemium)**:
  - Платные пакеты продвижения: **«Поднять в ТОП на 7 дней»** (`10 смн`), **«Выделение цветом»** (`8 смн`), **«Срочная продажа 🔥»** (`12 смн`) и **«Турбо-продажа 3-в-1»** (`24 смн` с экономией 20%).
  - Автоматический приоритет ранжирования в каталоге `/classifieds` и мгновенная активация через платёжный шлюз.

### 5. Платёжные шлюзы Таджикистана (`FinTech Payment Engine`)
- Единый чекаут (`POST /api/payments/checkout`) с поддержкой национальных платёжных методов:
  - **Корти Милли** (национальная платёжная система)
  - **Dushanbe City (`DC Next QR`)**
  - **Alif Salom / Alif Mobi**
  - **Эсхата Онлайн**
- Генерация динамического QR-кода, проверка статуса транзакции и выпуск фискальной квитанции.

### 6. Модуль сравнения объектов (`/compare`)
- Сравнение новостроек (`/projects`) и частных объявлений (`/classifieds`) в единой таблице характеристик.
- Режим **«Только отличия»**, автоматическая подсветка лучших показателей (минимальная цена за $\text{м}^2$, максимальная площадь, наличие рассрочки `0%`, ближайший срок сдачи) и плавающий виджет сравнения (`CompareFloatingBar`).

### 7. Рекламная платформа и Кабинет Суперадмина (`/advertiser`, `/super-admin`)
- **Аукцион нативной рекламы (`Ad Engine`)**: гибридный скоринг `eCPM` (`CPC` / `CPM` + `CTR` + `Quality Score`), частотный кэппинг (`Frequency Capping`), антифрод-защита кликов и строгая маркировка `Реклама`.
- **Кабинет рекламодателя (`/advertiser`)**: запуск кампаний, пополнение баланса через `Корти Милли / DC / Alif`, аналитика показов, кликов и `CTR`.
- **Кабинет Суперадмина (`/super-admin`)**: сквозная воронка метрик платформы, модерация рекламных баннеров и объявлений, управление застройщиками и финансовый биллинг.

### 8. Ипотечный и рассрочный калькулятор (`/calculator`, `/mortgage`)
- Сравнение программ банков Таджикистана (`Эсхата`, `Алиф`, `Амонатбонк`, `Имон Интернешнл`, `Хумо`) и беспроцентной рассрочки от застройщика с графиком платежей.

## Архитектура и структура репозитория

Проект построен по модульной четырёхслойной архитектуре с однонаправленным потоком зависимостей:
`app (маршруты и API)` $\rightarrow$ `components/modules (доменные фичи)` $\rightarrow$ `components/ui (атомарный UI-кит)` $\rightarrow$ `lib (бизнес-логика, сторы и типы)`.

│   └── specs/
│       └── SPEC_BOOKING_CALL_REQUESTS_CRM.md     # Полное ТЗ (15 разделов): Заявки на бронирование и звонки
├── src/
│   ├── app/                                      # Маршруты Next.js App Router и серверные API
│   │   ├── advertiser/page.tsx                   # Кабинет рекламодателя (Ad Engine)

## Запуск и локальная разработка

### Предварительные требования
- **Node.js** `>= 20.x` (рекомендуется `v22` или `v24`)
- **npm** `>= 10.x`

### Установка и старт
```bash
# 1. Перейти в директорию проекта
cd sogd-realty

# 2. Установить зависимости
npm install

# 3. Запустить сервер разработки (Turbopack)
npm run dev
```
После запуска приложение доступно по адресу [http://localhost:3000](http://localhost:3000).

### Сборка для продакшена
```bash
npm run build
npm run start
```

## Справочник REST API

| Метод и Endpoint | Описание |
| :--- | :--- |
| `GET /api/developer/crm-settings` | Получение статуса подключения CRM и тумблера «Сценарий бронирования и звонков» для застройщика (`?developerId=dev-1`) |
| `PATCH /api/developer/crm-settings` | Включение/отключение интеграции CRM и сценария бронирования (с авто-отключением тумблера при разрыве CRM) |
| `POST /api/crm/lead-booking` | Приём заявки на бронирование или обратный звонок: серверная проверка `Zero Client Trust`, пересчёт суммы сделки (`квартира + паркинг + кладовая`) в `TJS`, проверка чекбокса ПДн и защита от дублей |
| `POST /api/erp/sync` | Импорт и синхронизация шахматки, цен и статусов лотов из строительной ERP (`1С`, `Profitbase`, `MacroCRM`) |
| `GET /api/erp/sync` | Получение текущего состояния синхронизированного инвентаря и журнала `Audit Log` |
| `POST /api/payments/checkout` | Создание и проведение платежа через `Корти Милли`, `DC Next`, `Alif Salom`, `Эсхата Онлайн` |
| `POST /api/classifieds/vas` | Подключение платных VAS-услуг (`top_7d`, `color_highlight`, `urgent_fire`, `turbo_bundle`) к объявлению |
