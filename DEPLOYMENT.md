# Руководство по развертыванию демо-версии (Vercel + Neon / Supabase) 🚀

В этой инструкции описано, как за 5 минут развернуть публичный рабочий демо-стенд **Sogd Realty** на [Vercel](https://vercel.com/) с бесплатной облачной базой данных PostgreSQL на [Neon.tech](https://neon.tech/) или [Supabase](https://supabase.com/).

---

## 📋 Шаг 1. Создание облачной базы данных (Neon или Supabase)

### Вариант A: Neon.tech (Рекомендуется — создание за 30 секунд)
1. Перейдите на [neon.tech](https://neon.tech/) и зарегистрируйтесь (через GitHub/Google).
2. Нажмите **"New Project"**, укажите имя `sogd-realty`, регион выберите ближайший (например, `Frankfurt (eu-central-1)`).
3. В открывшемся окне скопируйте строку подключения **Connection String** (выберите **Pooled connection**):
   ```text
   postgresql://alex:AbCdEf123@ep-cool-fog-12345-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```

### Вариант B: Supabase
1. Перейдите на [supabase.com](https://supabase.com/) и создайте проект.
2. Откройте **Project Settings** $\rightarrow$ **Database** $\rightarrow$ **Connection Pooling**.
3. Скопируйте строку подключения (порт `6543` или `5432`):
   ```text
   postgresql://postgres.xxxx:your-password@aws-0-eu-central-1.pooler.supabase.com:6543/postgres?sslmode=require
   ```

## 🗄️ Шаг 2. Накатывание схемы и сидирование облачной базы

Выполните эти 2 команды локально на вашем компьютере, временно передав облачную строку подключения:

### 1. Создание таблиц в облачной базе данных (`db:push`)
```bash
# Для Neon / Supabase
DATABASE_URL="ваша_строка_подключения_из_шага_1" pnpm db:push
```
*Drizzle ORM автоматически создаст 10 таблиц, все перечисления (`sogd_city`, `user_role`, `unit_status` и др.), внешние ключи и уникальные индексы.*

### 2. Наполнение демо-стенда реалистичными данными (`db:seed`)
```bash
DATABASE_URL="ваша_строка_подключения_из_шага_1" pnpm db:seed
```
*Скрипт автоматически добавит:*
- ✅ Тестовых пользователей (администратор, риелтор, представитель застройщика, частный продавец).
- ✅ Ведущих застройщиков Согда («Рахш Сохтмон», «Сайҳун Девелопмент»).
- ✅ Жилые комплексы в Худжанде (ЖК «Сирдарё Плаза» в 19 мкр, ЖК «Суғдиён Сити» в 18 мкр).
- ✅ Полную поэтажную сетку квартир для интерактивной шахматки (108 юнитов с разными статусами, планировками и ценами в TJS/USD).
- ✅ Частные объявления вторичного рынка (квартиры, благоустроенный дом-хавли 6.5 соток в Б. Гафурове, коммерческое помещение у рынка Панчшанбе).

## 🌐 Шаг 3. Деплой проекта на Vercel

1. Загрузите код в ваш GitHub репозиторий:
   ```bash
   git push origin main
   ```
2. Откройте [Vercel Dashboard](https://vercel.com/dashboard) и нажмите **"Add New..."** $\rightarrow$ **"Project"**.
3. Выберите ваш репозиторий `sogd-realty`.
4. В блоке **Environment Variables** добавьте следующие обязательные переменные:

| Переменная | Значение (Пример) | Описание |
| :--- | :--- | :--- |
| `DATABASE_URL` | `postgresql://user:pass@ep-xyz-pooler.neon.tech/neondb?sslmode=require` | Строка подключения к облачной БД |
| `BETTER_AUTH_SECRET` | `sogd-realty-super-secret-key-min-32-chars-long-12345` | Секретный ключ для подписи сессий (любая случайная строка от 32 симв.) |
| `BETTER_AUTH_URL` | `https://sogd-realty.vercel.app` (ваш Vercel домен) | Базовый URL авторизации |
| `NEXT_PUBLIC_APP_URL` | `https://sogd-realty.vercel.app` (ваш Vercel домен) | Публичный URL приложения |
| `NEXT_PUBLIC_USD_TO_TJS_RATE` | `10.95` | Базовый курс пересчета валют сомони к доллару |

5. Нажмите кнопку **"Deploy"**.
6. Через 1–2 минуты ваш демо-стенд будет доступен по адресу вида `https://sogd-realty.vercel.app`! 🎉
